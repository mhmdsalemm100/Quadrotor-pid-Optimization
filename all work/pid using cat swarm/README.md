# pid using cat swarm

Source code for this study. See the [repository guide](../../README.md) for setup, scope, and limitations.

- `model.py`: plant and controller simulation.
- `study.py`: objective, scenarios, and supporting utilities.
- `config.json`: experiment settings and parameter bounds.
- `test_*.py`: supplied tests.
- `requirements*.txt`: dependencies.
- `source/`: original MATLAB/Simulink model source and readable XML.

Saved results, papers, figures, and reports are not distributed. Analysis, verification, comparison, and report-generation scripts require locally generated inputs. The original experiment code is preserved; its archived completion claims are not validation of a new run.
